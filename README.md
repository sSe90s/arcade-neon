# Arcade Neón

**Juega aquí: https://sse90s.github.io/arcade-neon/**

9 minijuegos retro con estética neón para jugar en el navegador, solo o con un amigo en el mismo teclado: motos de luz, meteoritos, pong turbo, tanques, bloques, metro rush, combates Pokémon, ruleta europea y Super Bomber.

Este repositorio solo contiene la versión publicada de la web (código minificado). El código fuente no es público.
